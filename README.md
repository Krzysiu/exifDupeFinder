# exifDupeFinder
CLI tool to find photo duplicates in PHP &amp; Python using ExifTool. Supports EXIF pattern matching, image hashing (visual duplicates), and smart caching.

### What is HOPE?

This project is built for **Maximum User Comfort**. The core philosophy is to provide a system that works perfectly by default, allowing you to step in only when you *want* to, not because you *have* to.

The **HOPE** acronym defines our development standards:

* **H** – **Human-centric**: Intuitive design tailored for tired eyes and busy minds. 
* **O** – **Optimal control**: A stable, open core that offers deep customization without sacrificing security.
* **P** – **Predictable**: Pure simplicity with zero surprises. You look at it, and you just know how it works.
* **E** – **Effortless**: Powerful defaults. The system thinks ahead so you don't have to.
